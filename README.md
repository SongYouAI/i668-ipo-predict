# 港股打新预测 · i668 增强（浏览器插件）

> **一句话**：拿过去 129 只港股新股的真实表现当「老师」，反推一只新股上市后（暗盘 / 首日）大概能涨多少，并**老实标出这个预测有多不靠谱**——区间窄 = 有把握，区间宽 = 这只在历史样本里本来就没规律。

在 [i668 港新工具箱](https://www.i668.vip) 的两处做增强，**不改动站点任何原有结构**。

### 数据会自动更新，不用重装

因子库（129 只）与模型参数（超购七档 / S3 偏移 / A+H 线性 / 基石权重 / 汇率）**不在代码里**，
而是运行时从 `dist/latest.json`（68KB）拉取，缓存到本机。改数据、重标定参数后，
使用者**不用重新安装**，下次打开页面自动用上（每 6 小时检查一次）。

想立刻拿到最新：点插件图标 →「更新数据」。若当前正开着 i668 页面，面板会多出一个
「刷新页面即刻生效」，点一下就完成 —— 这是**一键**，不用重装、不用碰 `chrome://extensions`。

只有改 `content/*.js` 算法时才需要重新分发代码。**代码更新没有静默通道**（不在应用商店），
但插件会自动发现并提醒：点「更新数据」时若远端 `appVersion` 高于本地，面板直接显示新版本号
和下载地址 —— 使用者不会在不知情的情况下一直用旧版。详见 [TECHNICAL.md](TECHNICAL.md) 的数据架构章节。

## 怎么用

### 列表页 `/stocks`
- 表格**最右追加三列**预测：招股期（S1）/ 中签后（S2）/ 暗盘后（S3），随阶段与大盘实时更新，**一屏全见**，站点原有列序 / 列宽 / 行高不动。

- 悬浮任一预测格：弹出摘要卡（锚 / 关键因子 / 区间 / 置信度 / 模型未纳入项）；点任一格进详情页。

### 详情页 `/stocks/<代码>`：「预测工坊」
页面顶部插入工坊卡片，五个区块：

| 区块 | 内容 |
|---|---|
| 三阶段预测 | 三张卡：模型区间 + 涨跌幅 + 置信度星级 + 状态（当前 / 已过 / 未到 / 已出实测）；每张卡可「改价」 |

| 实测数据 | 暗盘收盘 / 首日收盘（**只读**，标注站点口径） |
| 复盘 | 你设过且已有实测时，给出「你的设定 vs 实际」与高估/低估点数 |

## 预测原理（简要）

模型用 **2024–2026 共 129 只真实港股新股**当训练样本（其中 115 只「超购倍数 + 暗盘」齐全，用于分档标定），按**条件分位法**给每只新股一个带置信区间的预测：

- **中枢** = 该条件集（超购档位 / A+H 溢价 / 全样本兜底）的**中位数**；
- **区间** = 该条件集的 **[P25, P75]** 不对称分位（真实的 50% 中央区间，标称覆盖率）；
- **三阶段**：S1（招股期，无超购给方向性宽区间）、S2（中签后，核心预测）、S3（暗盘后，以暗盘为锚复盘）。阶段按**时间相位**判定，自动随打开日期刷新。
- **因子三态**：8 个已纳入打分 / 3 个只展示不入权重（绿鞋、发售结构、散户中签率）/ 2 个免费源拿不到（国配明细、未上市开盘价）。每个权重都做过实测消融，没有拍脑袋。

实测精度（`node tools/backtest.js` 可复跑，n=115）：**S2 区间名义 50%，实际命中 45.2%**，点估计误差中位 23.0pt；2026-07 后（n=31）命中 41.9%、误差 8.3pt。**区间越宽 = 这只真的没把握**，如实告知，比假装精确有用。

> 空窗期（招股已截止、配售结果未公布）会退到 A+H 溢价线性模型：n=39、命中 **53.8%**、误差 7.1pt、区间仅 21pt 宽。
> 但这是**样本内**成绩（同一批 39 只既用来标定又用来回测），真实样本外会低一些 —— 别拿 53.8% 当预期。

> 完整的数据源表、逐步手算、因子全表、消融实验与复现流程，见 [TECHNICAL.md 技术白皮书](TECHNICAL.md)。

## 数据来源与隐私

- **纯前端、免费、离线加载**；运行时只向 i668 接口与腾讯行情取数（均为公开免费源），**不向任何第三方上传你的数据**。
- **免费因子库**（保荐人战绩 / 首日开盘价 / 基石配售 / 绿鞋）由随插件加载的本地文件 `data/extras.js` 提供——构建期从 etnet 公开页与港交所招股章程抓取烤入，**插件运行时不请求这些站点**。
- **改价数据只存在本机** `chrome.storage.local`，不联网。

## 注意事项（踩过的坑，简要）

- **预测是统计推断，不是荐股、不保收益**——它是概率区间，不是承诺。
- **必须配合 i668 港新工具箱使用**：本插件是「增强」它的页面，不是独立站点。
- **免费源仍有两类拿不到**：国配明细（认购人结构，付费数据商内容）与未上市股的开盘价（尚未发生）。模型按中性处理，**用「改价」把你掌握的信息补进去**。
- **站点前端改版可能导致匹配失效**：列表侧浮条会如实报「未匹配到新股表格」，工坊侧显示「未能取得该股数据」，渲染异常逐格降级，不静默、不拖垮整表。

## 已知局限（说清楚，免得误用）

| 局限 | 具体到什么程度 | 界面怎么处理 |
|---|---|---|
| **高超购档样本极旧** | ≥500 倍档在 2026-07 后只有 0–1 只样本（6000 倍以上**一只都没有**），那几档参数基本是上半年高热环境的值，而市场 7 月已反转 | 工坊里逐档标注「样本 n=7（近期 1 / 历史 6，λ=0.11）」+「该档可能偏高，只当方向参考」 |
| **A+H 溢价关系已失效** | 2026-07 后溢价与暗盘的相关系数从 +0.43 掉到 +0.02，斜率被压到 0.086 | 计算过程里明写「该关系基本失效，只作很弱的方向参考」 |
| **A+H 降级成绩是样本内** | 53.8% 是同一批 39 只标定又回测的结果 | 本文档标注，不写进界面当卖点 |
| **暗盘只有收盘口径** | 站点不提供暗盘开盘价，所有「实测暗盘」都是收盘价 | 卡片上写「实测暗盘收盘」 |
| **破发概率是历史频率** | 按该档历史破发比例统计，**没做概率校准**（未做 Platt/isotonic），不是严格意义的概率 | 标注「该档历史上有 X% 收在发行价之下」 |
| **国配明细拿不到** | 认购人结构（谁是长线基金）是付费数据商内容，免费源一律不披露 | 因子表的「缺失」清单里明列 |
| **S1 只有方向** | 招股期没有超购数据，只能给宽区间，非 A+H 时完全靠名称推断赛道 | 置信封顶 ★☆☆，标注「名称推断」 |
