# 安装说明（给使用者看的，不用懂技术）

这是一个浏览器插件，在 [i668 港新工具箱](https://www.i668.vip/stocks) 的新股列表上多显示三列预测：**招股期 / 中签后 / 暗盘后**，点进个股还能看到每一步是怎么算出来的。

免费、纯前端，**不上传任何数据**。

---

## 一、安装（只做一次，约 2 分钟）

### 第 1 步：拿到安装包

作者会直接发你一个 `i668-ipo-predict.zip`（微信/网盘都行），存到「下载」文件夹。

> 如果作者给的是 `.command`（Mac）或 `.bat`（Windows）脚本，双击它就行，它会自己找安装包。
> 找不到包时会尝试联网下载（约 110MB，慢）。

### 第 2 步：解压到一个不会被删的地方

- **Mac**：双击脚本 → 自动解压到 `你的用户目录/i668-港股打新插件/i668-ipo-predict`
- **Windows**：双击脚本 → 自动解压到 `C:\Users\你的用户名\i668-extension\i668-ipo-predict`

不想用脚本？自己解压也行，但**不要放在「下载」或「桌面」**（容易被清理工具删掉）。放好后记住这个文件夹位置。

### 第 3 步：让浏览器加载它

1. 打开 Chrome（或 Edge），地址栏输入：`chrome://extensions/`
   Edge 用 `edge://extensions/`
2. 打开右上角的 **「开发者模式」** 开关
3. 点左上角 **「加载已解压的扩展程序」**
4. 选中第 2 步那个文件夹（里面应该有 `manifest.json`）
5. 列表里出现「港股打新预测 · i668 增强」就成功了

### 第 4 步：验证

打开 <https://www.i668.vip/stocks>，表格右侧应该多出三列预测。

## 二、更新（以后作者改了东西怎么办）

分两种，**绝大多数情况你什么都不用做**：

| 作者改了什么 | 你要做什么 |
|---|---|
| 因子库（新股数据）、模型参数（重新标定） | **什么都不用做**。下次打开页面自动同步 |
| 程序代码（新功能、修 bug） | 双击一次安装脚本，回 `chrome://extensions` 点一下那个 ⟳ 刷新按钮 |

自动同步说明：插件每 6 小时检查一次云端参数（约 68KB），有更新会提示「刷新生效」，点一下就更新完了，**不用重新安装**。

想立刻检查：点浏览器右上角的插件图标 → 「检查数据更新」。

## 三、常见问题

**Q：每次打开 Chrome，右上角都提示「请停用开发者模式扩展程序」，是不是中毒了？**
不是。这是 Chrome 对所有「非应用商店安装」的扩展的统一提示，只要点 × 关掉就行。这个插件不在应用商店（因为依赖第三方网站数据），所以必然出现。

**Q：装完看不到预测三列？**
依次检查：
1. 当前网页是不是 `https://www.i668.vip/stocks`（其他页面不显示）
2. `chrome://extensions/` 里插件是不是启用的
3. 刷新一下网页（⌘R / F5）
4. 窗口太窄？把浏览器窗口拉宽一点

**Q：详情页显示「跨域受限：浏览器不允许直读」？**
说明浏览器拒绝了读取港交所 PDF。点下面那个「招股章程 PDF ↗」可以自己看原文。这不影响预测，只影响「绿鞋」那一项。

**Q：预测准吗？**
区间命中率约 45%（名义 50%），也就是**一半多一点会落在区间外**。它是参考，不是保证。详细局限见 README 的「已知局限」。

**Q：会收集我的数据吗？**
不会。所有计算在你本机浏览器里完成，只有两类外部请求：① 拉取 i668 公开行情；② 拉取云端参数（一个 68KB 的 JSON）。没有任何数据上传。
