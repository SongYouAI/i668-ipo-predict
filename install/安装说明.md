# 安装说明（给使用者看的，不用懂技术）

这是一个浏览器插件，在 [i668 港新工具箱](https://www.i668.vip/stocks) 的新股列表上多显示三列预测：**招股期 / 中签后 / 暗盘后**，点进个股还能看到每一步是怎么算出来的。

免费、纯前端，**不上传任何数据**。

---

## 一、安装（只做一次，约 2 分钟）

### 第 1 步：下载安装包

**固定下载地址（建议收藏，以后更新也是这一个）：**

<https://github.com/SongYouAI/i668-ipo-predict/releases/latest/download/i668-ipo-predict.zip>

点开就直接开始下载，**不用登录、不用在页面上找按钮**。文件约 1.5MB。

> ⚠️ 地址在 GitHub 上，**需要能正常访问 GitHub**（有代理就没问题）。
> 打不开就找作者要 zip，微信发你的同样能用。

### 第 2 步：解压，放到一个不会被删的地方

解压后会得到一个 `i668-ipo-predict` 文件夹 —— **这个文件夹就是要装的东西**，先记住它在哪。

- 建议放：Mac 的「文稿」、Windows 的「文档」
- **别放「下载」或「桌面」**：容易被清理工具删掉，删了插件就失效，得重装

不想手动操作也可以用作者给的脚本（Mac 双击 `.command`，Windows 双击 `.bat`），它会自动解压到固定目录并清理多余文件。

### 第 3 步：让浏览器加载它

1. 打开 Chrome（或 Edge），地址栏输入：`chrome://extensions/`
   Edge 用 `edge://extensions/`
2. 打开右上角的 **「开发者模式」** 开关
3. 点左上角 **「加载已解压的扩展程序」**
4. 选中第 2 步那个文件夹（**选里面带 `manifest.json` 的那一层**）
5. 列表里出现「港股打新预测 · i668 增强」就成功了

### 第 4 步：验证

打开 <https://www.i668.vip/stocks>，表格右侧应该多出三列预测。

## 二、更新（以后作者改了东西怎么办）

分两种，**绝大多数情况你都不用重新安装**：

| 作者改了什么 | 你要做什么 |
|---|---|
| 因子库（新股数据）、模型参数（重新标定） | 点插件图标 → **「更新数据」**。如果你正开着 i668 页面，会多出一个「刷新页面即刻生效」，点它就行。**不用重装** |
| 程序代码（新功能、修 bug） | 再点一次第 1 步那个固定地址，下载最新 zip → 解压覆盖原来的文件夹 → 回 `chrome://extensions/` 点插件卡片上那个 ⟳ 刷新按钮 |

**怎么知道代码该更新了？** 点「更新数据」，插件如果发现自己的代码版本落后，会直接在面板上写出新版本号，并给一条能点开的下载地址。

自动同步的细节：插件每 6 小时自己检查一次云端参数（约 68KB），有更新会在页面底部弹出提示条，点「刷新生效」即可。

## 三、常见问题

**Q：每次打开 Chrome，右上角都提示「请停用开发者模式扩展程序」，是不是中毒了？**
不是。这是 Chrome 对所有「非应用商店安装」的扩展的统一提示，点 × 关掉就行。这个插件不在应用商店（因为依赖第三方网站数据），所以必然出现。

**Q：下载地址打不开 / 一直转圈？**
这个地址在 GitHub 上，国内直连经常连不上。挂上代理再点，或者直接找作者要 zip。

**Q：装完看不到预测三列？**
依次检查：
1. 当前网页是不是 `https://www.i668.vip/stocks`（其他页面不显示）
2. `chrome://extensions/` 里插件是不是启用的
3. 刷新一下网页（⌘R / F5）
4. 窗口太窄？把浏览器窗口拉宽一点
5. 是不是选错了文件夹层级（必须是含 `manifest.json` 的那一层）

**Q：详情页显示「跨域受限：浏览器不允许直读」？**
说明浏览器拒绝了读取港交所 PDF。点下面那个「招股章程 PDF ↗」可以自己看原文。这不影响预测，只影响「绿鞋」那一项。

**Q：预测准吗？**
区间命中率约 45%（名义 50%），也就是**一半多一点会落在区间外**。它是参考，不是保证。详细局限见 README 的「已知局限」。

**Q：会收集我的数据吗？**
不会。所有计算在你本机浏览器里完成，只有两类外部请求：① 拉取 i668 公开行情；② 拉取云端参数（一个约 68KB 的 JSON）。没有任何数据上传。
